# Portfólio — André Dalsochio

## Desenvolvimento

```sh
npm install
npm run dev
```

## Atualizar os projetos

Edite `lib/portfolio.ts` e adicione itens à lista `projects`. A seção “Em breve” é substituída automaticamente pela lista. Cada projeto recebe nome, descrição, tecnologias e links opcionais para site e repositório. Não é necessário mudar o layout.

## Conteúdo e visual

- `app/page.tsx`: textos e estrutura.
- `lib/portfolio.ts`: links pessoais e projetos.
- `app/globals.css`: cores, tipografia e responsividade.
- `app/layout.tsx`: título e descrição para buscadores.

```sh
npm run build
```
